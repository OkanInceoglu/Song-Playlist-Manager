# Song Playlist Manager

A console-based playlist management application written in C++.

## Features

- Create and display playlists
- Store song information, including name, artist, year, and genre
- Add and remove songs
- Search for songs by name
- Search for songs by artist
- Track the number of times a song has been played
- Compare and sort songs using overloaded operators

## Concepts Used

- Object-Oriented Programming (OOP)
- Classes and objects
- Constructors
- Getters and setters
- Operator overloading
- `std::map`
- `std::vector`
- Iteration and conditional statements

## Technologies

- C++
- Standard Template Library (STL)

## How to Run

Compile the source files using a C++ compiler that supports C++11 or later.

Example:

```bash
g++ -std=c++11 main.cpp Song.cpp PlayList.cpp -o playlist
```

Run the application:

```bash
./playlist
```

On Windows, run `playlist.exe`.

## Purpose

This project was developed to practice C++ programming, object-oriented design, and STL containers.
